### PUYA_orgel_FireDPT

# 🧸 PY32F002Aマイコン搭載 電子オルゴールプロジェクト。

安価でコストパフォーマンスに優れたPUYA製マイコン「PY32F002A」を使用した、おもちゃ修理・換装用の電子オルゴールプロジェクトです。
緊急車両のサイレン効果音を、電子オルゴールで実装することを原点とし、開発者へのリスペクトを込めて公開されています。

---

## 🛠 プロジェクトの概要と特徴
手ころがしで遊ぶ消防車・救急車やパトカーなどの緊急車両のおもちゃ、基板上のCOB故障に備えてサイレン効果音の再現を目指し、外部メモリ不要なマイコン換装による治療選択肢を準備しています。
- **SW_F002A_8_FireDPT** : 8ピン `PY32F002A`を採用、緊急車両のサイレン効果音を、電子オルゴールで再現する。
- **楽しく遊べる設計**：タクトSW、2個のLED点滅をサポート。加えて、CVDタッチセンスも簡単に選択実装選択が可能。
- **省エネ・省コスト**：電力消費効率に優れた `BTL=3`出力で電池２本での運用に好適、狭小なおもちゃケースに収まる省スペース設計。

## 🗺 開発の歩みとこれからの展望（FritzingからEasyEDAへ）

本プロジェクトは、手探りの試行錯誤から始まりました。

* **これまでの歩み**：10年前から回路図ソフト「Fritzing」（当時の無料版）を愛用してきましたが、現行版の制約などもあり、PUYAマイコンの部品データを手動で書き起こし、片面ユニバーサル基板にジャンパ線を多用しながら配線を実現してきました。
* **次世代への承継に向けた一歩**：新人ドクターを迎え、我流のやり方を見直す中で「EasyEDA」に出会いました。一から勉強を開始し、部品ライブラリから `PY32F002A` を発見。基板レイアウトの練習を兼ねてオリジナル基板の発注（JLCPCB等への一気通貫での発注）までを体験・実現しました。
* **これからの目標**：今後はこのEasyEDAを活用したスマートな基板設計へ移行していく予定です。
